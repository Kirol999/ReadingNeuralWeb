# Reading Neural Web · 读书成长历程

一个 3D 交互式的读书成长历程可视化网站：每本书是一个白色光点，关联关系用白色细线连接，整体呈神经网络形态，可拖拽旋转视角、缩放、悬停查看书名。

## 功能

- **中心节点**：可设置多个，作为结构的核心
- **并列关系**：同一层级的书籍围成圆环，自动建立关联
- **包含关系**：上下延伸形成沙漏状结构，支持多级嵌套
- **节点数量无上限**：布局自动扩环、扩层
- **右键设旋转中心**：右键点击某个节点，即可围绕它旋转视角
- **命名存档**：保存 / 载入 / 删除多套网络
- **新建神经网络**：一键开始全新网络（原内容自动备份）

## 使用

直接打开 `index.html` 即可使用（数据保存在浏览器 localStorage 中）。

- 左侧操作条：选择关系类型（中心 / 并列 / 包含）→ 选择参照节点 → 输入书名 → 添加
- 拖拽旋转视角 · 滚轮缩放 · 悬停看书名 · 右键设旋转中心
- 点击节点查看详情，点击书单条目可聚焦
